# Drawer 表现规范

> 英文公共语义源：[drawer.md](drawer.md)。

## 职责

本文档负责 Drawer 精确布局、字体、组件几何和视觉状态数值。[Drawer 行为](../surfaces/drawer.zh-CN.md)负责应用清单、排序、状态、选择与操作结果；[导航](../navigation.zh-CN.md)负责转换阈值；[设计基础](../design-foundations.zh-CN.md)负责共享颜色与字号 token；[样式设置面板表现](style-settings-panel.zh-CN.md)负责与 Home 共用的面板表面和控件；[图标形状](../features/icon-shape.zh-CN.md)负责应用图标的剪裁模式与圆角比例。

## 界面与应用内容

- Drawer 在状态栏安全 inset 下使用高 `56dp` 的顶部应用栏。该栏在当前选定的 Drawer 背景上保持视觉透明，不创建自身独立表面。返回箭头使用 `24dp` 图形，居中于从安全起始边缘 `12dp` 处开始的 `48dp` 交互目标中，图形起始边缘因此距安全起始边缘 `24dp`；普通模式下该目标在起始侧预留区内水平居中，保持同样的图形位置。
- 一条全宽 `1dp`、共享 `secondaryTextColor` 的分割线在顶栏的全部状态——普通、搜索和收藏多选——下将顶部应用栏与正下方内容分隔，遵循[设计基础](../design-foundations.zh-CN.md)定义的共享顶栏分割线处理。分割线在每个背景不透明度百分比下渲染一致，且不会使顶栏成为不透明表面。
- 名称右置的条目由通过[样式设置面板](style-settings-panel.zh-CN.md)尺寸块独立选择的应用图标尺寸与应用名称（文字）尺寸组合而成。可见图标在图标档位为大、中、小时分别为 `48dp`、`40dp`、`32dp`，距条目顶部 `8dp`、底部 `12dp`。条目高度准确为图标上方 `8dp`、下方 `12dp`，仅当所选名称行无法容纳于同一上下边界之间时才增高，此时名称行垂直居中、上方 `8dp`、下方 `12dp`。完整条目仍是选择和长按目标，按压 Ripple 覆盖完整条目，不因条目自身 padding 缩小。
- 名称右置时，所有图标与文字档位组合的图标名称间距均为 `12dp`。名称按大、中、小文字档位分别使用正常字重的共享 `largeAppNameFontSize`、`primaryTextFontSize` 与 `secondaryTextFontSize`，配合各自共享行高和 `primaryTextColor`。
- 名称下置时，每项在图标上方使用 `8dp`，图标名称间距为 `12dp`，单行名称下方使用 `12dp`；条目高度因此准确为 `8dp` + 所选图标尺寸 + `12dp` + 所选名称行高 + `12dp`。名称占据一个横跨完整条目内容宽度的文本框，每侧可见内容 inset 准确为 `8dp`，文字在该文本框内水平居中；图标在条目内水平居中。相邻条目的名称文本框因此正好相距 `16dp`，不再增加独立列间距。隐藏名称时不渲染名称：图标距条目顶部 `8dp`、底部 `12dp`，并在条目内水平居中，条目高度因此准确为 `8dp` + 所选图标尺寸 + `12dp`，文字档位对隐藏名称条目没有影响。
- 应用网格边界距安全起始边缘 `8dp`，并结束于安全末端 AlphabetIndex 预留区之前 `8dp`。每个条目自身增加 `8dp` 起止可见内容 inset，使首尾可见内容最终距适用外部边界 `16dp`，相邻条目的可见内容之间形成 `16dp`，不再增加独立列间距。实现不得同时重复增加容器和条目 inset，导致这些可观察总距离发生变化。
- 列之间使用 `0dp` 独立间距，并按受宽度约束后的有效每行条目数量平分可用应用网格宽度。
  所有渲染名称均使用静态单行和尾部省略。
- 可用宽度变窄时，所选图标和文字尺寸保持不变。每行生效条目数量等于所选数量，
  但会受当前名称位置允许范围和可完整容纳条目的宽度限制，最低保持一列。因此窗口
  极窄时仍保持一列，不压缩或裁切条目。所有应用继续通过增加行保持可用，降低生效列数
  不会移除应用或改变其顺序。左侧锚点、AlphabetIndex 预留区、外部边距和条目 inset
  都计入可用应用网格宽度。
- 在所有图标与文字档位组合下，所选数量范围为名称右置一至二、名称下置一至四、隐藏名称一至六。
  实际等宽列使用上文有效数量；窗口变窄不改写已保存的所选数量。步进控件显示并操作所选数量。
  到达所选数量边界时，其目标保留普通几何，但使用共享禁用表现并暴露 disabled 状态，不显示可操作 Ripple。
  控件未因动画或保存而临时锁定时，名称位置变化会在同一帧更新边界表现。
  下列示例指所选数量，不一定等于实际呈现列数：以二切换到`下方`时启用加号；
  以三或四切换到`右侧`时显示二并禁用加号；切换到`隐藏`时保留数量，低于六时启用加号；
  从`隐藏`切换到`右侧`或`下方`且数量超过目标上限时，分别收敛为二或四并禁用加号。

## 背景不透明度与对比度

- Drawer 背景把一层全界面 `darkSurfaceBaseColor` 按用户所选不透明度百分比合成到壁纸上。`0` 在完整 Drawer 中保持壁纸清晰，`100` 呈现完整纯色表面；中间百分比呈现该颜色与壁纸的混合。背景不增加模糊、玻璃效果或该层之外的其他 scrim，不采样壁纸，也不根据列表位置、指针位置、搜索结果或局部明度改变。
- 所有百分比下，文字和单色前景图形使用 `primaryTextColor` 和一套固定、跟随字形或图形轮廓的深色投影，参数使用下方已接受值。低百分比下的前景对比度依赖这些处理；明亮壁纸上的可读性是用户选择的权衡，以作者设备验收为准。
- 背景不透明度只改变 Drawer 背景和适用的对比度处理；顶部应用栏、应用、锚点、搜索、AlphabetIndex、Settings、多选、模态层和交互几何均不改变。

## 搜索框与命中强调

- 顶部应用栏包含一个高 `40dp` 且相对屏幕独立居中的搜索框。普通返回和展示设置控件替换为搜索模式的左侧空白预留与右侧`取消`后，搜索框仍保持居中。两侧预留和搜索框可以根据安全宽度调整，但不得重叠或使搜索框偏离屏幕中心。
- 搜索框内部透明，圆角为 `20dp`。前置放大镜和条件式尾部 X 的可见图形均为 `20dp`；内部 start 与 end inset 为 `12dp`，图形与文字间距为 `8dp`。X 居中位于至少 `48dp x 48dp` 的交互目标中；虽然可见搜索框较矮，该目标仍须位于完整的 `56dp` 顶部应用栏交互区域内。
- 提示与查询文字使用正常字重的共享 `primaryTextFontSize` 及其行高。英文提示为`Search apps`，简体中文提示为`搜索应用`。提示颜色使用 `secondaryTextColor`，输入文字使用 `primaryTextColor`。
- 非搜索模式使用 `1dp` Material `outline` 边界；搜索模式使用共享短时长颜色／属性动画 token，将边界变为 `primaryTextColor` 的 `2dp` 高亮。搜索模式仍生效时，查询为空、键盘隐藏或文字焦点暂时丢失均不移除高亮边界。
- 物理右侧`取消`文字使用中等字重的共享 `secondaryTextFontSize`、对应行高和 `primaryTextColor`，交互目标至少高 `48dp` 且宽度足以容纳完整本地化标签。对应的物理左侧预留与右侧等宽，但不提供可见控件、交互、焦点或无障碍节点。
- 应用名称的命中片段使用 `primaryTextColor` 和中等字重；未命中文字保留适用的普通样式。强调不增加背景、下划线、独立 padding、单独语义节点或几何变化。
- 无匹配提示在可用应用区域居中，使用正常字重的共享 `primaryTextFontSize`、对应行高和 `primaryTextColor`，不显示错误图标、进度指示器或重试呈现。

## 分组锚点与字母索引

- 分组锚点使用粗体的共享 `largeAppNameFontSize`、对应行高和 `primaryTextColor`。内嵌锚点占据全宽 `40dp` 行，文字垂直居中，起始位置距安全起始边缘最终总计 `16dp`，并随列表滚动而不吸顶。左侧锚点占据 `40dp` 宽的起始侧列，与剩余应用网格之间间距为 `0dp`；文字水平居中，在未吸顶时距所属分组顶部 `8dp`，进入分组范围内吸顶后继续保持相同几何并位于顶部应用栏下方。Settings 左侧锚点用 `16dp x 16dp` `primaryTextColor` 齿轮图形替代文字，在该列水平居中并保持相同 `8dp` 顶部距离。两种锚点均不会因为吸顶改变布局，也不建立交互目标。
- AlphabetIndex 在安全末端边缘占据固定 `32dp` 宽度，并在可用应用区域内垂直居中。标签在固定 `20dp` 槽位中使用 `11sp` 中等字重文字；Settings 齿轮使用 `11dp` 图形并位于一个完整 `20dp` 槽位内。
- 最大索引模型包含 28 个固定槽位。由 Drawer 行为契约负责最终可用高度阈值和滚动决定。
- 活动 token 气泡由 `64dp` 圆形主体和朝向 AlphabetIndex 的 `12dp` 尖端组成，完整尺寸为 `76dp x 64dp`。背景为浅灰色 `#CC8A8A8A`。气泡在可用应用区域内保持垂直居中，尖端位于 AlphabetIndex 起始侧，两者间距为 `16dp`。`32sp` 中等字重文字或 `32dp` Settings 齿轮居中于圆形主体。气泡不随当前有效槽位进行纵向移动。
- Drawer Loading 使用共享 `48dp x 48dp` 进度指示器尺寸，Error 使用共享 `48dp x 48dp` 非交互状态图标尺寸。状态文字使用正常字重的共享 `primaryTextFontSize`、对应行高和 `primaryTextColor`。指示器或图标与文字间距为 `16dp`；Error 文字与 Retry 间距同样为 `16dp`。

## Settings 固定条目

- 固定 Settings 条目至少高 `56dp`，使用 `40dp` `primaryTextColor` 齿轮、`16dp` 图标名称间距，以及正常字重的共享 `primaryTextFontSize` 名称、对应行高和 `primaryTextColor`。
- 该条目从安全起始边缘 `16dp` 处开始，内容结束于 AlphabetIndex 预留区之前；该预留区由安全末端内容 inset `16dp` 加固定 `32dp` 索引宽度组成。完整条目是交互目标，齿轮不建立重复目标或说明。

## Error 布局

- 固定顶部应用栏下方，状态图标、提示文字和重试在安全应用区域内组成居中的纵向堆叠。
  它们使用上文 Loading/Error 的尺寸和间距；重试复用标准 Material 3 文字按钮及共享交互目标规则。
- 普通 Error 在重试后放置一个 Settings 条目，间距复用提示文字与重试之间的 `16dp`。
  包含 Settings 的完整堆叠垂直居中。设置行复用[固定条目](#settings-固定条目)的高度、
  齿轮、文字、间距、水平几何及组合交互目标，包括安全末端预留。
  该预留保持空白；Error 不绘制分组标题、锚点或 AlphabetIndex。
- 收藏多选 Error 使用不带设置行的同一状态堆叠，遵循
  [Drawer 行为](../surfaces/drawer.zh-CN.md#多选期间的可用性状态)。

## 收藏多选

- 收藏多选顶部应用栏继续高 `56dp`，使用起始、中间和末端三个内容区域。起始侧`取消`和末端侧`确认`控件分别使用垂直居中的 `48dp` 高热区并贴合对应安全边缘，热区内部起止内容 padding 均为 `12dp`。文字自身继续使用共享字号和自然行高，不把“文字高度”设置为 `48dp`。
- 两侧预留宽度都取完整本地化`取消`与`确认`目标测量宽度中较大者，使其保持对称并让目标说明在物理屏幕上居中。中央说明使用剩余宽度，保持单行末尾省略，且不得与两侧操作重叠；三个区域均垂直居中。
- 多选条目沿用普通清单的每行数量网格与排列；条目几何与普通 Content 一致，选择状态不改变任何布局。多选条目不显示按压 ripple；选择缩放与描边处理即其可见响应。
- 可用且未选中的条目不显示任何选择指示；多选模式由顶部应用栏表达。
- 选中条目以纯视觉变换缩放至约 `90%`（布局边界不变，取消选择恢复 `100%`，动画使用共享短时长属性动画 token），并绘制完整 `2dp` `primaryTextColor` 选中边框、`12dp` 圆角。
- 选中条目在左上角覆盖一枚顺序徽标：`primaryTextColor` 背景、以 `darkSurfaceBaseColor` 的中等字重共享 `secondaryTextFontSize` 及对应行高显示从一开始的顺序、左上与右下圆角 `12dp`、其余两角直角；徽标最小约 `20dp` 并随内容自适应，其内容含 `4dp` 水平内边距，覆盖于条目之上、不占布局空间，也不是独立交互目标。
- 已收藏且禁用的条目不显示徽标、边框或缩放，图标和名称使用共享禁用语义透明度。

## 显示设置

- Drawer 把共享[样式设置面板](style-settings-panel.zh-CN.md)作为可以从底部进入的紧凑自定义表面承载。它使用共享水平外边距，并增加 Drawer 专属底部外边距。面板打开与关闭使用一次高度属性动画——打开时高度从 `0` 生长至内容高度，关闭时原路收回——使用共享短时长属性动画 token（参考时长约 `200ms`），与 Home 样式面板一致。透明模态层阻止底层输入，但不调暗露出的 Drawer 或系统背景；共享边框必须使面板与两层露出背景保持清晰分层。
- Drawer 专属底部外边距沿用当前实现中已由作者实机认可的表现，
  本规范不要求预先确定精确值。该参数由实现维护，可在作者实机验收下调整。
  底部安全区域 inset 与宿主 padding 各只计算一次，不得在面板底部间距中重复叠加。
- Drawer 通过共享面板展示四个设置块：分组锚点、应用排列、应用尺寸和 Drawer 背景。分组锚点控件使用共享紧凑双选项选择器；名称位置（`右侧／下方／隐藏`）控件与每行条目数量步进控件共用排列块内容行，分别使用共享紧凑选择器与步进控件；应用尺寸块使用共享双收缩滑杆控件选择图标与文字档位。Drawer 继续自行定义设置名称、选项文案、可用性与保存行为。
- Drawer 背景块在其内容行上呈现一个百分比读数和一个背景不透明度滑杆，行几何、读数处理与滑杆强调色使用[样式设置面板呈现规范](style-settings-panel.zh-CN.md)定义的共享背景行几何：物理左侧固定宽度百分比读数、`16dp` 间距、占满剩余宽度的连续滑杆。
