# 应用操作面板

> 英文语义源：[app-action-sheet.md](app-action-sheet.md)。精确视觉数值见[应用操作面板表现规范](../presentation/app-action-sheet.zh-CN.md)；空间草图见共享的[应用操作面板线框](../wireframes/app-action-sheet.txt)，阅读规则见[线框索引](../low-fidelity-wireframes.zh-CN.md)。

## 呈现

应用操作面板是模态 Bottom Sheet。普通 Home 中长按一个已经完整呈现的收藏会打开它；
Drawer 普通模式中长按应用后，未开始[拖动收藏](drawer.zh-CN.md#拖动收藏)而抬起时也打开它。
Home 长按触觉之后的移动不会进入[一次操作模式](home.zh-CN.md#一次操作模式)。
Drawer 长按触觉之后移动超过 touch slop，则改为开始拖动收藏，由 [Drawer 交互规格](drawer.zh-CN.md)定义。
Home 分为普通、编辑和一次操作三种状态。编辑模式中，允许应用级编辑的区域把应用长按保留给移动。
打开的样式设置面板只阻断所属模块内的应用级目标，其他模块仍允许应用级编辑。
编辑模式和一次操作模式均不打开本面板。

- 使用深色表面与浅色文字，并保持系统状态栏图标为浅色。
- 顶部显示一条浅色短横线作为拖动柄。
- 底层界面覆盖灰色遮罩。
- 面板采用 Material 3 标准模态 Bottom Sheet 的拖动阈值、速度处理、回弹和嵌套滚动仲裁，不另行规定产品数值。面板内容仍可滚动时先消费滚动；内容到达顶部后继续向下可以通过该标准行为关闭面板。
- 点击遮罩、完成标准向下关闭或按 Back 均可关闭。所有关闭路径都不执行未选择的操作，并保留底层界面位置。
- 关闭前，底层应用界面不能接收点击、长按或滚动。
- 接受操作时，将关闭面板作为该操作交付的一部分；下文各操作规则分别负责最终目标和失败行为。当前产品定义不增加独立的成功反馈。
- 从 Home 或 Drawer 启动选中的普通应用时，先关闭面板并形成
  [导航](../navigation.zh-CN.md#android-系统-home-操作与外部应用返回)定义的外部应用暂离。
  同一进程返回时显示 Home，不显示 Loading，也不恢复 Drawer。

## 内容顺序

从上到下依次为：

1. 左侧应用名称和右侧应用信息控件。
2. 浅色内缩分割线。
3. 可选的应用快捷操作区：包含平台提供的快捷操作，每项由图标和名称组成。下方继续展示启动器操作时，该区域末尾包含同样的内缩分割线。
4. 横向排列的启动器操作，每项的图标在上、名称在下。Home 展示取消收藏、编辑和卸载；Drawer 仅展示卸载。

精确图标、分割线和 badge 几何由[应用操作面板表现规范](../presentation/app-action-sheet.zh-CN.md)定义。

一个可选的信息区位于应用身份分割线正下方、应用快捷操作区之前，按顺序渲染至多两行不可交互的只读文字：无操作行，然后是非默认行。无操作行在面板没有应用快捷操作也没有启动器操作时展示。非默认行在 Launcher4Max 不是设备默认桌面时展示；两个宿主都在面板打开时评估该状态。每行是一条本地化文案——无操作行为`暂无可用操作`，非默认行为`未设为默认桌面`——两者都只是信息提示：不是交互目标，不增加 Toast 或确认，也不改变任何关闭或操作行为。精确行几何由[应用操作面板表现规范](../presentation/app-action-sheet.zh-CN.md)定义。

平台没有提供应用快捷操作时，隐藏完整应用快捷操作区及其拥有的分割线。两个宿主上，应用身份下方分割线继续作为启动器操作前的边界；快捷操作区存在时，同一条分割线在两个宿主上将其与启动器操作行分隔。

当前契约不为异常多的平台快捷操作定义专门的溢出交互；只有真实应用证明存在需要后，才作为可叠加能力补充。无论数量如何，实现不得崩溃，也不得绘制到受保护的系统界面区域。

面板内容超过可用高度时，只有应用快捷操作区纵向滚动；应用身份行、信息行和适用的启动器操作行保持可见。这种有边界的滚动只是普通内容容纳方式，不属于上文排除的异常快捷操作专属溢出能力。

## 应用身份与信息

- 应用名称不可点击。
- 顶部不展示应用图标。
- 对应用分身，在 Bottom Sheet 右下角独立展示平台提供的分身 badge，以遵循作者三星设备上观察到的身份提示方式。
- Badge 对齐 Bottom Sheet 右下角，不设置向外偏移；精确视觉区域由应用操作面板表现规范定义。
- Badge 仅用于装饰，不接收输入、不占用启动器操作槽位，也不为其预留内容布局空间；主应用不展示。
- 点击信息图标后进入系统应用信息界面。
- 从系统应用信息返回时不恢复面板，并刷新对应应用状态。
- 系统应用信息界面无法打开时，展示短 Toast `无法打开应用信息`，关闭面板，保留底层 Home 或 Drawer 位置，并且不改变收藏状态。

## 启动器操作

- 启动器操作在两个宿主上都可用。Home 展示取消收藏、编辑和卸载；Drawer 仅展示卸载，位于最左侧槽位。
  普通 Home 可通过本面板直接取消收藏，也可通过编辑操作进入编辑模式。
  其他收藏管理入口遵循 Home 与 Drawer 交互规格。Drawer 条目的系统管理入口仍为应用信息。
- Home 启动器操作使用从左到右排列的五个固定横向槽位。可见操作从最左侧槽位开始紧缩排列；隐藏操作不留下中间空位，未使用槽位保留在右侧。操作不在整个宽度中重新均分。
- 每个启动器操作的完整“图标 + 标签”条目是一个交互目标；图标不是独立或更小的触控目标。
- 启动器操作最多五项；该限制不适用于平台应用快捷操作。
- Home 操作顺序为取消收藏、编辑、卸载。编辑在只有一个收藏时仍然可用；卸载不可用时隐藏，后续可见操作向左移动。
- 点击编辑后关闭面板，在当前主列表位置和采用织带布局的织带位置进入样式设置面板收起的
  Home 应用级编辑模式；不选择模块、不滚动、不显示其他模块，也不展开样式设置面板。
  流式布局织带没有独立横向位置。该操作同时请求一次非阻断清单刷新，不延迟进入编辑。
- 如果由该编辑操作触发的刷新可靠确认来源身份已经消失，Home 按普通清单规则协调收藏，并显示本地化短 Toast `应用已不可用`。编辑过渡提交前已经存在可靠消失结果时不进入编辑，协调后停留在普通 Home；进入后才收到确认时，继续遵循 Home 编辑模式清单规则。不确定或失败的读取既不显示该 Toast，也不移除收藏。
- 从 Home 取消收藏时，关闭面板、移除对应 Home 条目，并沿用 [Home 交互规范](home.zh-CN.md#新增移除与移动应用)定义的同一本地化移除 Snackbar、最近一次移除 Undo 快照、替换、失效、恢复与失败行为。
- 系统不允许卸载或只允许停用时，不展示卸载。
- 对应用分身，只有平台能够确认操作仅删除当前选中分身、不会卸载主应用时，才展示卸载。无法保证时隐藏卸载，并保留通过应用信息进入系统管理的渠道。绝不把“删除分身”降级成“卸载主应用”。
- 破坏性确认和实际删除行为由系统控制。
- 用户取消系统卸载确认后，返回原 Home 或 Drawer 位置，不恢复面板，并刷新应用状态。
- 系统卸载界面无法打开时，展示短 Toast `无法打开卸载界面`，关闭面板，保留底层 Home 或 Drawer 位置，并且不改变收藏状态。
- 当前产品范围不为平台应用快捷操作调用失败增加独立处理。

## 图标

- 取消收藏：裂开的爱心。
- 编辑：纵向箭头。
- 卸载：垃圾桶。
- 应用信息：信息符号。

最终图标资产及无障碍描述由视觉和实现规格补充。
