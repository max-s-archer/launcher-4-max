# Settings 交互规格

> 英文语义源：[settings.md](settings.md)。精确视觉数值见 [Settings 表现规范](../presentation/settings.zh-CN.md)；空间草图见共享的 [Settings 线框](../wireframes/settings.txt)，阅读规则见[线框索引](../low-fidelity-wireframes.zh-CN.md)。

## 入口与返回

- 页面标题为 `设置`。
- 固定顶部应用栏展示页面标题和一个可见返回控件。点击该控件与系统 Back 结果相同；两条路径都不会打开其他目标，也不会重置 Drawer 位置。
- Settings 只能通过普通 Drawer 的设置条目进入：Content 时位于列表末尾分组，
  Error 时位于重试下方。AlphabetIndex 齿轮只导航到 Content 中的该分组，不打开 Settings。
- 同一进程内 Back 返回 Drawer，保留此前 Content 列表位置，
  或按 [Drawer 错误契约](drawer.zh-CN.md#空结果或读取失败)保留 Error 状态。
  往返 Settings 不重试也不清除该 Error。
- 从 Error 进入后，备份、恢复、快捷操作设置和隐私等 Settings 入口仍按既有规则可用，
  无需等待应用清单恢复。备份和恢复操作已保存的收藏与设置，不修复应用清单读取失败。
- Settings 使用不透明的标准 Material 3 dark color scheme。它与 Home、Drawer 的区别是会绘制 Material 表面背景，不透出应用下方的系统背景。两个预览窗口是透明例外：[icon-shape.zh-CN.md](../features/icon-shape.zh-CN.md) 定义的图标形状窗口，以及 [home-bottom-app-bar.zh-CN.md](../features/home-bottom-app-bar.zh-CN.md) 定义的主页底部常驻应用栏窗口。二者都透出系统壁纸而不读取壁纸。Settings 其余全部区域保持不透明。

## 当前契约

### Launcher 设置

- **默认主屏幕应用：** 展示当前默认 Launcher 状态，并打开系统默认主屏幕应用设置。
- 标题为 `默认主屏幕应用`；副标题根据当前系统状态显示 `已设为默认启动器` 或 `未设为默认启动器`。
- 从系统界面返回后立即刷新副标题。
- **快捷操作设置：** 打开 [quick-actions.zh-CN.md](../features/quick-actions.zh-CN.md) 定义的快捷操作设置页。该页列出两个基础信息区槽位行及其当前绑定，以及承载无障碍授权入口与披露流程、始终可见的锁屏服务状态行。服务关闭时选择 `锁屏` 会进入该流程，且不影响已保存的绑定。
- 每个槽位独立绑定 `无操作`、`编辑模式` 或 `锁屏`。两个槽位默认均为 `无操作`，Launcher4Max 不做任何唯一性、互斥或跨槽位校验。绑定变更立即生效并在本地持久化。
- Settings 不再单独显示锁屏项。该页面及其选择弹窗的行为由 [quick-actions.zh-CN.md](../features/quick-actions.zh-CN.md) 负责。
- **图标形状：** 打开 [icon-shape.zh-CN.md](../features/icon-shape.zh-CN.md) 定义的图标形状设置页。该入口是标题为 `图标形状` 的主要设置项，位于 `快捷操作设置` 正下方、数据区条目之上。页面、其实时预览窗口及其模式与圆角控件的行为由该契约负责。
- **主页底部常驻应用栏：** 打开 [home-bottom-app-bar.zh-CN.md](../features/home-bottom-app-bar.zh-CN.md) 定义的页面。该入口是标题为 `主页底部常驻应用栏` 的主要设置项，位于 `图标形状` 正下方、数据区之上。总开关、预览、固定式和图标大小由该页面负责。

### 语言行为

- 当前产品为所有面向用户的字符串提供英文和简体中文资源。
- Launcher4Max 根据当前系统语言区域自动选择资源。简体中文使用简体中文资源，英文使用英文资源；不支持的语言区域回退为英文。
- Settings 不包含应用语言设置项或手动语言选择器。
- 系统语言改变后，Launcher4Max 自动切换到对应的受支持资源，不要求用户在 Launcher4Max 中另行选择。
- 手动选择应用语言属于未来可叠加能力，不在当前契约中定义。

### 数据

该标题只用于组织行为契约，不是 Settings 中可见的分组标题。下面两个入口按所列顺序以主要设置项的形式纵向叠加展示：`备份收藏与设置` 在上，`从备份恢复` 在下。两者都会打开系统界面，因此都显示主要设置项的右侧箭头；两者都不带副标题。

- **备份收藏与设置：** 点击后打开系统文档选择器选择本地保存位置。Launcher4Max 提供建议文件名 `launcher4max-backup-<版本名称>-<yyyyMMddHHmm>`，例如 `launcher4max-backup-1.6.0-202609071913.json`，由当前应用版本名称和设备本地日期时间构成；最终文件名与保存位置由系统选择器决定。写入的是一个 JSON 文件，其中包含当前完整的 Home 收藏状态（有序收藏模块的类型、顺序、稳定身份、样式和模块内应用顺序，以及主页底部常驻应用栏状态：是否开启、是否固定、所选图标大小和放在应用栏上的有序收藏身份）以及完整的 Drawer 显示设置（应用图标尺寸、应用名称尺寸、名称位置、每行数量、分组锚点表现，以及背景不透明度百分比）和完整的快捷操作绑定（每个基础信息区快捷操作槽位绑定的动作）以及完整的图标形状偏好（剪裁模式与已保存的自定义圆角比例）。文件带 schema 版本号且不加密；不需要新增权限。导出文件由用户管理，位于 Launcher4Max 应用私有存储之外。
  - 取消或关闭文档选择器时不写入任何内容、不产生任何变化，也不显示提示。
  - 写入进行期间，数据区的两个入口均不可交互。备份被中断时当前应用状态不受影响；写了一部分的文件按恢复规则视为无效备份。
  - 备份成功显示本地化短提示 `收藏与设置已备份`；写入失败显示本地化短提示 `无法备份收藏与设置`。
- **从备份恢复：** 点击后打开系统文档选择器选择备份文件。取消或关闭选择器时不产生任何变化，也不显示提示。
  选择文件后显示确认弹窗，说明确认后将使用备份内容替换当前 Home 收藏
  （包括主页底部常驻应用栏的成员与设置）、Drawer 显示设置、快捷操作绑定和图标形状偏好，
  且该操作无法撤销。弹窗提供 `恢复` 与 `取消` 操作；`取消`、关闭弹窗和 Back 都不产生任何变化。
  确认后以一次原子操作把完整当前状态替换为备份状态，并显示本地化短提示 `收藏与设置已恢复`。
  Settings 保持显示；Home 和 Drawer 在下一次展示时呈现恢复后的状态。
  - 恢复不对备份执行当前应用清单校验；随后由普通清单刷新规则处理——禁用身份保留、确认消失的身份移除、启动失败显示普通启动失败反馈。
  - schema 兼容具有方向性：schema 版本高于当前应用 schema 的备份为版本不兼容；schema 版本等于或低于当前 schema 的备份被接受，并按当前 schema 解释。
  - 缺少某一状态节的备份仍然有效：缺少收藏节时恢复为空的收藏状态，缺少 Drawer 显示设置节时将显示设置恢复为 Launcher4Max 默认值，缺少快捷操作绑定节时把所有槽位恢复为 `无操作`，缺少图标形状节时恢复完整的图标形状默认值（`OEM 剪裁`，已保存比例为 `50`），缺少主页底部常驻应用栏节时恢复为关闭且没有收藏放在应用栏上；已存在状态节内缺失的字段按所属功能契约的字段规则恢复。图标形状中，缺少模式使用 `OEM 剪裁`，`自由剪裁` 模式缺少比例使用 `50`，模式或比例非法时使用对应字段默认值；如果两字段无法形成有效形状偏好，则整个图标形状偏好恢复默认值。非法比例不进行裁剪，备份中的其他有效节仍然恢复。有效的主页底部常驻应用栏节包含的身份超过恢复后的图标档位和 Home 当前宽度容量时，按备份中应用栏保存的顺序保留前 `N` 个有效身份，其余身份不转入其他模块，只从恢复后的应用栏中省略。不含任何模块的空备份有效。
  - 不可读、格式错误或版本不兼容的文件在不覆盖当前状态的前提下失败，并显示本地化短提示 `无法从备份恢复`。
  - 恢复不触发一次性 Home 模型采用重置；Launcher4Max 不做任何自动备份或上传该文件。

### 关于

该标题只用于组织行为契约，不是 Settings 中可见的分组标题。

- **隐私：** 打开 [privacy.zh-CN.md](../features/privacy.zh-CN.md) 定义的本地隐私 Bottom Sheet。
- **Launcher4Max License：** 打开本地 Launcher4Max License Bottom Sheet；英文统一使用 `License`。
- **第三方声明：** 打开独立的本地 Bottom Sheet。面板列出随 release 应用分发的组件，并说明它们均适用 Apache License 2.0。正文是 `res/raw/third_party_notices.txt` 中的离线文本。仅用于开发和测试的组件不包含在内。该入口与 Launcher4Max License 保持独立。
- **项目仓库：** 通过隐式系统浏览器调用打开已配置的项目仓库链接。
- **版本信息：** 使用 `v<版本名称>(<versionCode>)` 格式，例如 `v1.6.0(7)`；不可点击，也不支持复制。

### 支持与诊断

当前支持上文定义的手动本地备份与恢复。复杂日志、更新检查、自动备份、云同步、诊断导出，
以及复制版本或设备信息均不在当前产品契约内。

## 隐私呈现

- 点击隐私后，打开深色模态 Bottom Sheet，展示本地可读的隐私声明；当前不建立独立隐私页面。
- 其外框、固定标题和可滚动正文遵循 [Settings 表现规范](../presentation/settings.zh-CN.md#信息-bottom-sheet)。
- 隐私声明必须支持离线阅读。
- 面板的遮罩、顶部拖动柄、下拉关闭、点击遮罩关闭和 Back 关闭行为与应用操作面板一致。
- 隐私内容超过面板可用高度时纵向滚动；关闭后返回 Settings 原位置。
- 展示内容采用 [privacy.zh-CN.md](../features/privacy.zh-CN.md) 中当前面向用户的 Privacy 正文，其中包含当前本地数据、备份、删除、外部链接、权限和锁屏边界。
- GitHub Issues 联系地址可点击，并使用该 Privacy 契约定义的隐式浏览器和本地化失败行为。

## License 呈现

- Launcher4Max License 与第三方声明是两个独立的 Settings 入口。
- 两者均打开深色、本地且可离线阅读的内容；长内容可以纵向滚动。
- 两者的外框、固定标题和可滚动正文遵循 [Settings 表现规范](../presentation/settings.zh-CN.md#信息-bottom-sheet)。
- 模态关闭方式和 Settings 位置恢复行为与隐私 Bottom Sheet 一致。

## 设置项角色

### 主要设置项

- 主要设置项包含标题、可选副标题；打开其他目标时显示右侧 Android 或 Material 箭头。快捷操作设置页的条目即使打开的是本地选择弹窗，也保留该箭头，以与 Settings 页视觉一致。
- 主要设置项的字体、颜色角色、行几何、padding 和箭头尺寸由 [Settings 表现规范](../presentation/settings.zh-CN.md)定义。

### 次要信息项

- 隐私、Launcher4Max License、第三方声明、项目仓库和版本信息使用次要呈现。
- 次要项不显示右侧箭头。可点击入口仍然可以点击；版本信息不可点击。
- 次要项的字体、颜色角色、行几何和对齐由 Settings 表现规范定义。

## 项目仓库

- Launcher4Max 不预先检测网络连接；浏览器打开后，由系统浏览器处理离线或网络错误。
- 没有系统应用能够处理仓库链接或隐式调用失败时，展示短 Toast `无法打开项目链接`，并保持当前 Settings 位置。
- 当前不提供复制仓库链接的操作。

## 状态刷新

- 从系统设置界面返回时，刷新受影响的 Launcher 状态。
- 离开应用进入系统界面后，不恢复此前打开的模态面板。
