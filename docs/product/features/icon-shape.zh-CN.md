# 图标形状交互规格

> 英文公共语义源：[icon-shape.md](icon-shape.md)。Settings 入口、其位置与透明例外记录在 [Settings 交互规格](../surfaces/settings.zh-CN.md)；页面与预览窗口的精确几何属于 [Settings 表现规范](../presentation/settings.zh-CN.md#图标形状设置页)。

## 目的与范围

图标形状允许用户控制应用图标的剪裁方式，而不是把剪裁固定为设备默认。本契约登记唯一一个全局形状偏好，它只有两种模式：

- `OEM 剪裁`：应用图标保持当前交付的设备默认剪裁结果。这是所有安装——全新安装与升级安装——的默认模式。
- `自由剪裁`：每个图标的方形底图按用户选择的一个圆角比例剪裁。

整个产品只有一个形状偏好。它不按界面、按模块或按图标区分；同一界面内出现混排形状、形状预设、按模块的形状覆盖以及任何第二形状维度都不在当前契约内。未来扩展属于可叠加契约变更。

## 形状偏好

- 偏好解析为两种模式之一。切换模式立即生效，并随完整设置状态本地持久化。
- 最近一次保存的自由剪裁比例在模式切换间保留：选择 `OEM 剪裁` 不重置该比例，再次选择 `自由剪裁` 时恢复使用。
- 从未保存过比例的全新配置在首次选择 `自由剪裁` 时以 `50` 起始。
- `自由剪裁` 模式下，比例是一个 `0` 至 `100` 的整数百分比：`0` 渲染不倒角的方形底图，`100` 渲染完整圆形。渲染圆角为所选比例乘以适用图标槽位的一半，因此同一比例在所有图标尺寸下呈现相同的相对形状。
- `OEM 剪裁` 模式下不应用已保存的比例，模式切换也不改变它。选择 `OEM 剪裁` 时，圆角控件按共享禁用表现报告不可用。
- 模式变更立即生效，并针对完整形状偏好启动一次独占保存。保存尚未完成时，
  其他形状变更不可用，但顶部应用栏返回控件与系统 Back 仍可用。页面不提供单独的确认操作。
  拖动圆角比例时只实时预览，不改变已保存状态；抬手时一次性提交最终值，
  指针取消、Back 或外部中断时恢复最近一次成功保存的值。
  保存失败时恢复最近一次成功保存的完整偏好，显示本地化短 Toast `无法保存图标形状`，
  且页面已经关闭时不重新打开。后续有效变更可以重试。

## 适用范围

- 形状偏好适用于 Home 纵向模块、横向织带条目、主页底部常驻应用栏中的应用图标，
  以及 Drawer 应用图标在该列表所有状态（包括搜索结果与收藏多选）下的呈现。
- 应用操作面板中的平台快捷操作图标，以及产品内的所有功能性图形（新增收藏入口图形、箭头、锚点、状态与服务图形）都不是应用图标，不跟随形状偏好。
- 偏好只改变图标剪裁，不改变图标槽位尺寸、模块几何、启动行为或其他契约拥有的任何表现数值。

## Settings 界面

Settings 包含一个标题为 `图标形状` 的主要设置项，位于 `快捷操作设置` 正下方、数据区条目之上，它打开本文件定义的独立页面。页面复用 Settings 页面结构与顶部应用栏（含返回控件），Back 返回 Settings 此前位置。

- 页面在底部一个设置块之上呈现一个实时预览窗口。精确几何属于 [Settings 表现规范](../presentation/settings.zh-CN.md#图标形状设置页)；空间草图为[图标形状设置页线框](../wireframes/icon-shape-settings.txt)。
- **实时预览窗口：** 一个内部完全透明的圆角矩形。
  它不读取、采样、复制或绘制壁纸。系统壁纸透过该内部保持可见。
  预览区域占满应用栏与设置块之间的空间；窗口在该区域内内缩，具体定义见
  [Settings 表现规范](../presentation/settings.zh-CN.md#图标形状设置页)。
  页面自身不滚动。该窗口与主页底部常驻应用栏预览窗口是 Settings 中透出壁纸的两处位置。
  窗口内部，准确三个纵向堆叠、不可交互的行在窗口内水平与垂直居中，
  每行对应一个图标档位：大、中、小，并以当前偏好结果渲染固定样例图标，
  即系统默认应用图标。预览样例不使用真实已安装应用。
  拖动圆角控件时各行实时更新，每行携带标识其档位的本地化无障碍名称。
- **设置块：** 预览下方的设置块遵循共享样式设置面板的"标题行+内容行"语言。它包含一个 `剪裁模式` 内容行，使用紧凑双选项选择器提供 `OEM 剪裁` 与 `自由剪裁`；以及一个 `圆角比例` 内容行，组合整数百分比读数与暴露 `0`–`100` 的一个连续滑杆。读数、滑杆范围处理与禁用表现复用共享控件；选择 `OEM 剪裁` 时滑杆不可交互。
- 页面自身不滚动；预览区域吸收剩余垂直空间。
  Settings 自身的进入、返回与状态刷新行为不变。
- 每行预览在图标右侧显示带档位的本地化示例应用名称，图标与名称整体居中，
  已有本地化档位无障碍名称只播报一次。具体文案及样式属于
  [Settings 表现规范](../presentation/settings.zh-CN.md#图标形状设置页)。

## 备份与恢复

- 形状偏好——其模式与已保存比例——是手动备份文件的一部分，并遵循其 schema 规则。
- 缺少偏好节时恢复完整默认形状偏好：模式为 `OEM 剪裁`，已保存比例为 `50`，
  供之后切换到 `自由剪裁` 时使用。缺少模式字段时使用 `OEM 剪裁`。
  已存在 `自由剪裁` 模式但缺少比例时保留该模式并使用比例 `50`。
  `OEM 剪裁` 模式下缺少或非法比例时使用比例 `50`，不影响当前 OEM 呈现。
  未知、空值或其他非法模式使用 `OEM 剪裁`，备份中的其他有效节仍可恢复。
  超出范围、非整数、空值或其他非法比例使用 `50`，备份中的其他有效节仍可恢复。
  如果模式和比例无法共同解析为一个有效形状偏好，则整个形状偏好恢复默认值，
  备份中的其他有效节仍可恢复。非法比例不进行裁剪。

## 验收意图

- Given 默认偏好，when 呈现 Home 纵向模块、织带条目、主页底部常驻应用栏或 Drawer 图标，
  then 每个应用图标保持设备默认剪裁结果，不应用任何自定义圆角。
- Given `自由剪裁` 及任意已保存比例，when 大、中、小图标在 Home 纵向模块、织带条目、
  主页底部常驻应用栏与 Drawer 中呈现，then 每个应用图标呈现相同的相对圆角形状：比例乘以其槽位一半。
- Given `自由剪裁` 为 `100`，when 呈现任何应用图标，then 其渲染为完整圆形；为 `0` 时渲染为方形。
- Given 页面打开且处于 `自由剪裁`，when 用户拖动圆角滑杆，then 三个预览行实时更新但不改变已保存状态；抬手时一次性提交最终值且不需要确认操作。取消拖动时恢复最近一次成功保存的值。
- Given 已选择 `OEM 剪裁`，when 展示页面，then 圆角滑杆以禁用表现报告不可用，且已保存比例不变。
- Given 用户在保存过比例后从 `OEM 剪裁` 切换到 `自由剪裁`，then 该已保存比例重新生效。
- Given 全新配置，when 首次选择 `自由剪裁`，then 比例以 `50` 起始。
- Given 页面打开，when 呈现预览窗口以外的任何区域，then 该区域保持标准不透明 Settings 表面。预览窗口不读取或绘制壁纸；其内部完全透明，因此系统壁纸从三个样例图标后方透出。
- Given 备份包含有效偏好，when 恢复完成，then Home 纵向模块、织带条目、
  主页底部常驻应用栏与 Drawer 呈现与备份一致的形状。
  Given 偏好节缺失，then 模式为 `OEM 剪裁` 且已保存比例为 `50`；given 已存在
  `自由剪裁` 模式但比例缺失，then 保留 `自由剪裁` 且比例为 `50`。
  Given 模式或比例非法，then 非法字段按对应默认值恢复；如果两字段无法形成有效偏好，
  then 整个形状偏好恢复默认值。备份中的其他有效节仍然恢复，非法比例不被裁剪。
- Given 已选择 `自由剪裁`，when 应用操作面板中呈现平台快捷操作图标，then 它们保持平台渲染，不跟随该比例。
- Given 用户在页面触发系统 Back 或返回控件，then Settings 打开于此前位置。
  已成功保存的变更保持已保存；指针尚未抬起的圆角预览被取消，恢复最近一次成功保存的值，不启动保存。
  已经开始的保存独立完成：成功则保留新偏好，失败则恢复最近一次成功保存的完整偏好，
  并显示 `无法保存图标形状`。两种结果均不重新打开页面。
