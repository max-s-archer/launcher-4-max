# 导航与界面层级模型

> 英文语义源：[navigation.md](navigation.md)。

## 职责

本文定义 Home、Drawer、Settings 与应用操作面板之间当前的层级、入口、退出、恢复和公共过渡行为。本文不规定 Home 与 Drawer 必须实现为两个独立 Compose 页面，或实现为同一个可拖动容器中的两个功能区域。

## 初始界面

- Launcher 启动或进程重建后，以 Home 作为初始界面。
- 即使后续实现使用同一个 draggable 容器，Home 与 Drawer 仍是两个不同的产品功能界面。
- Settings 只能通过普通 Drawer 的设置条目进入：Content 时位于末尾分组，Error 时位于重试下方，
  由 [Drawer 行为](surfaces/drawer.zh-CN.md)定义。
  AlphabetIndex 齿轮只导航到 Content 中的该分组，不直接打开 Settings。
- Home 不提供 Settings 入口。

## 过渡模型

Home 与 Drawer 使用同一套可逆、跟手的直接操作过渡。以下术语定义其可观察行为：

- **手势偏移量：** 沿目标界面方向累计的拖动距离；反向移动会将累计距离逐步减小到零。
- **手势进度：** 手势偏移量除以 200dp，并限制在 0 到 1。200dp 是当前完整手势距离，未来可以通过产品变更重新调整。
- **Drawer 跟手位移：** 手指保持按下期间，手势每移动 1dp，Drawer 移动 1.5dp；进入和退出均使用 1:1.5 映射。
- **界面完整行程：** Drawer 在屏幕下方的屏外位置与屏幕顶部的最终位置之间移动。200dp 手势距离不表示屏幕高度只有 300dp。
- **停靠动画：** 松手结果确定后，系统从当前跟手位置自动补完到选定端点的剩余屏幕距离。用户不需要把 Drawer 手动拖过完整屏幕高度。

### 透明度

透明度依据手势进度计算，不依据 Drawer 已移动屏幕距离的百分比。设手势进度为 `p`：

- Home 内容透明度为 `max(0, 1 - 2p)`。
- Drawer 内容透明度为 `min(1, 2p)`。
- 进度 0% 时，Home 完全可见，Drawer 完全透明。
- 进度 25% 时，两个界面的内容透明度均为 50%。
- 进度 50% 时，Home 完全透明，Drawer 完全可见。
- 进度 50%–100% 时，Home 保持完全透明，Drawer 保持完全可见，同时位置继续变化。

反向过渡按相同数值倒序执行。回弹和补完动画必须从当前位置与透明度连续执行，不得跳变。

### 松手判定

- 手势进度达到或超过 60%，即 120dp 时，完成到目标界面的过渡。
- 低于 60% 松手时返回来源界面，除非该次松手构成指向目标方向的 fling。
- 指向目标方向的有效 fling 即使低于 60% 也完成切换。速度阈值和检测方式属于实现细节，但必须保持该可观察结果。
- 反向 fling 不得继续进入目标界面，应返回来源界面。
- 手势取消或被系统中断时，沿相同的位置与透明度路径返回来源界面。
- 额外触点不产生产品行为，不得导致位置跳变、反向切换、误触应用或同时出现第二个过渡。

## Home 进入 Drawer

- 普通 Home 模式下，上滑是用户通过手势进入普通 Drawer 的唯一入口。Home 编辑模式中的新增收藏入口可以通过程序触发完成同一向上过渡并进入 Drawer 收藏多选模式；这不会在编辑模式中启用 Home→Drawer 拖动。从收起的主页底部常驻应用栏露出部分开始的点按或短距离上滑改为展开该应用栏，规则见 [home-bottom-app-bar.zh-CN.md](features/home-bottom-app-bar.zh-CN.md)。它不启动应用，也不开始这一过渡。已经完整呈现的收藏在长按触觉之后移动超过平台 touch slop 时，手势归[一次操作模式](surfaces/home.zh-CN.md#一次操作模式)所有，既不滚动列表，也不开始这一过渡。
- 在 Home 正常模式下，上滑可从 Launcher4Max 的 Home 交互区域内任意位置起始，包括时间、日期、收藏条目、空状态、加载状态、错误状态和 Retry 控件；系统保留区域中的系统手势仍由 Android 管理。
- 纵向上滑首先使收藏主列表滚向末端。主列表无法继续消费偏移量时，同一次连续手势的剩余偏移立即转交给 Home→Drawer 过渡，不要求用户抬手。过渡进度从转交后的偏移开始计算，不包含已被列表滚动消费的距离。
- 下滑使收藏主列表滚向起始位置，不触发 Home 界面过渡。只有建立横向意图后，织带布局的横向收藏织带才消费手势；流式布局的织带继续属于主列表纵向滚动。
- Home 编辑模式生效期间禁用 Home→Drawer 拖动。样式面板未打开的模块上，完整应用条目长按被识别后取得应用移动所有权。模块排序拖动柄的拖动取得模块移动所有权，无论面板是否打开。其他纵向拖动负责滚动收藏主列表。
- 一次触控序列只能产生一种 Home 操作。在可交互元素的点击或长按操作提交之前，一旦识别为向上拖动，手势所有权即转交给 Home→Drawer 过渡，并取消该元素的点击、长按和对应触觉反馈。
- 基础信息区符合条件的空白位置中，双击或长按解析为 [quick-actions.zh-CN.md](features/quick-actions.zh-CN.md) 定义的对应快捷操作槽位所绑定的动作；绑定为 `无操作` 的槽位不解析出任何动作。任何已经取得过渡所有权的拖动都会取消该识别。时间、日期星期、收藏及其他交互目标永不参与绑定的空白手势。
- 只有在抬手前该触控序列未成为向上拖动或长按时，才提交点击操作。长按一旦被识别并打开对应操作，同一次触控序列不得再启动 Drawer 过渡。
- 触控序列被取消时不执行点击或长按；如果 Home→Drawer 拖动已经取得手势所有权，则按照界面过渡的取消规则处理。

## Drawer 返回 Home

- 系统 Back 通过反向过渡的补完路径从 Drawer 返回 Home。
- Drawer 普通模式顶部应用栏中的返回箭头也通过相同补完路径返回 Home。
- 下滑时先将应用列表滚向顶部边界。
- 列表滚动偏移量大于零时，下滑偏移量只由列表消费，Drawer 不开始退出。
- 同一次连续下滑中，列表偏移量到达零后，剩余偏移量立即转交给 Drawer→Home 过渡，不要求用户抬手后再次下滑。
- 界面过渡接管剩余手势后，列表保持在顶部边界，直到过渡停靠完成。

## Back 与恢复

- Home 上的 Back 先由当前最具体的活动状态处理，再执行普通 Home 结果：
  活动中的应用或模块移动会取消该移动并消费 Back；活动中的模块名称文本编辑会结束
  `EditText` 会话并隐藏键盘，但不回退已经保存的名称；已打开的样式设置面板会关闭并保留编辑模式；
  展开的半隐藏底部栏仅在普通 Home 且上述状态均未活动时收起。完成这些状态专属处理后，
  Launcher4Max 已是系统默认 Launcher 时，Home 上的 Back 不产生可见行为；
  未设置为默认 Launcher 时，Launcher4Max 执行普通系统 Back 行为，不规定最终返回的外部目标。
- Drawer 上的 Back 返回 Home。
- Settings 上的 Back 返回进入前的 Launcher4Max 界面，当前即 Drawer。
- 同一进程内往返 Settings 保留来源 Drawer 的 Error 状态，不触发重试，
  遵循 [Drawer 行为](surfaces/drawer.zh-CN.md#空结果或读取失败)。
- 快捷操作设置页只能由其 Settings 项进入，并且是 Settings 的子页面而不是独立界面。在该页上 Back 返回 Settings 并保留 Settings 此前位置；页面在进程重建后不恢复，与其他不恢复的临时界面一致。
- 应用操作面板上的 Back 关闭面板，并返回保持不变的底层界面。
- Home 编辑模式中，Back 先关闭已打开的样式设置面板，否则退出到普通 Home。Drawer 收藏多选模式中，Back 先取消全部未确认选择并通过反向过渡返回 Home 编辑模式，不会同时退出编辑模式。
- 进程重建后从 Home 开始，不恢复 Drawer、Settings、应用操作面板、编辑模式及瞬时
  面板或选择状态。同一进程内普通 Launcher4Max 往返保留收藏主列表有意义的纵向
  位置和每条采用织带布局的织带有意义的横向位置；进程重建后均回到内容起点。

## Home 编辑模式中断

- Home 编辑模式只在 Home 保持为完整前台、可交互的 Launcher4Max 界面期间有效。任何覆盖 Home 输入或把交互移出 Home 的系统／外部中断都会退出编辑模式，包括打开通知栏或快捷设置、显示最近任务、锁屏或熄屏、打开其他应用，或展示其他由系统拥有的界面。
- 中断会取消所有进行中的手势或未发布的应用／模块移动、关闭样式设置面板，并关闭仅属于编辑模式的视觉反馈；已经成功保存的变更继续保留。已经开始保存的原子变更遵循既有成功或失败规则，但无论结果如何都不得恢复编辑模式。如果 Launcher4Max 只能在 Home 再次可交互时观察到中断结果，必须在接受新的 Home 输入前完成该重置。因此，关闭中断后只能看到普通 Home，不恢复先前的应用级或模块级编辑状态。
- 属于同一编辑旅程的 Launcher4Max 自有步骤不视为外部中断：展开或收起内嵌样式设置面板、显示 Launcher4Max 确认控件或移除 Snackbar，以及进入 Drawer 收藏多选或从中返回，继续遵循各自已经定义的状态规则。

## Android 系统 Home 操作与外部应用返回

- 当 Launcher4Max 被选为默认 Launcher 时，从任意 Launcher4Max 界面（包括 Home 编辑模式、
  Drawer、Drawer 收藏多选模式、Settings 和快捷操作设置页）执行 Android 系统 Home
  操作都会显示普通 Launcher4Max Home。活动中的收藏多选会被取消，编辑模式也会退出。
  同一进程内，普通 Home 保留最近一次成功完成的滚动或编辑所形成的主列表有意义位置和
  采用织带布局的织带位置；流式布局织带没有独立横向位置可保留。取消尚未完成的手势不会产生
  新位置。这属于系统导航结果，不是 Launcher4Max 的 Back 或 Drawer→Home 过渡；
  Launcher4Max 不得将 Android 系统 Home 操作重新解释为 Back。本契约中未加限定的
  `Home` 只表示 Launcher4Max 产品界面，永远不表示该平台操作。
- 从 Home 或 Drawer 启动普通应用会形成一次外部应用暂离。当 Launcher4Max 在同一进程中返回时，显示 Home 而不是恢复 Drawer；在展示已有 Home 内容前，不显示 Loading，也不要求执行一次阻塞式新的初始读取。
- 同一进程返回时，保留 Home 收藏状态、收藏主列表有意义的纵向位置和每条织带布局
  采用织带布局的织带有意义的横向位置。流式布局织带没有独立横向位置可恢复。不恢复 Drawer、
  Settings、应用操作面板、编辑模式或进行中的 Drawer 位置。
- 外部应用运行期间观察到的变化应在不将返回的 Home 替换为 Loading 的前提下协调。更新后的应用清单和收藏状态在下次展示 Drawer 或相关 Home 内容时可用，并遵循各界面的实时更新规则。
- 如果外部应用运行期间 Launcher 进程被重建，则适用进程重建规则，不适用同一进程返回规则。

## 系统界面

- Home 与 Drawer 显示系统状态栏。
- Home 保持透明应用表面；Drawer 的应用背景遵循其当前选定的背景模式，不由本导航契约定义。
- Home 与 Drawer 请求透明状态栏和导航栏区域，并在其下方进行 edge-to-edge 绘制。Launcher4Max 不增加独立的不透明系统栏背景；适用的 Home 或 Drawer 界面处理继续由对应表现规范负责。
- Launcher4Max 保留平台和设备默认的对比度保护行为。适用 Android 版本在三键导航等情况下提供的系统半透明保护层，不由 Launcher4Max 替换或强制关闭。
- 系统导航栏和导航控件跟随用户当前的系统导航模式；Launcher4Max 不隐藏它们，也不进入沉浸模式。
- Home、Drawer、Settings 和所有应用操作面板使用 dark theme 与浅色前景元素。打开面板时不得把状态栏图标切换为深色样式。
- 即使 Home 与 Drawer 在透明系统栏后方进行 edge-to-edge 绘制，内容和交互目标仍必须避让系统栏、屏幕开孔和系统手势 inset。

## 验收意图

- 上滑 100dp 时，手势进度为 50%，Drawer 在停靠前的跟手位移为 150dp。
- 未构成有效 fling 时，在 119dp 松手返回来源界面；在 120dp 或更大距离松手完成到目标界面。
- 低于 120dp 的有效目标方向 fling 仍完成到目标界面。
- 用户反向移动、松手、补完或回弹时，位置和透明度都保持连续；Drawer→Home 从 Drawer 列表滚动转交手势时也保持连续。
- 在 Home 正常模式下，上滑能够从每个由 Launcher4Max 管理的 Home 元素上起始，且不得同时触发该元素的点击或长按。已经完整呈现的收藏在长按触觉之后移动超过 touch slop 时改为换序，不滚动，也不打开 Drawer。
- Drawer 列表到达顶部前，下滑只滚动列表；到达顶部后，剩余偏移量在同一次手势中转交给退出过渡。
- 打开或关闭 Drawer 时不得误触发应用点击、长按或列表滚动。
- Launcher4Max 作为默认 Launcher 时，从 Drawer 和 Settings 执行 Android 系统 Home 操作都显示 Home，不依赖 Launcher4Max 的 Back 操作。
- 同一进程从普通应用返回时显示 Home，不显示 Loading，也不恢复 Drawer。
- 从系统或外部中断返回时，永不恢复 Home 编辑模式、打开的样式设置面板或未发布移动。
- 实现可以选择任何满足上述可观察行为的架构。
